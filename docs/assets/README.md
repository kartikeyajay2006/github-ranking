# 🎨 Documentation assets

## 🟦 `brand/`

This folder contains the paired light and dark SVG illustrations displayed by the GitHub README.

- `hero-light.svg` and `hero-dark.svg` introduce the product.
- `how-light.svg` and `how-dark.svg` illustrate how assessment totals and team weighting fit together.
- `access-light.svg` and `access-dark.svg` explain the private-instance access path.

The files are generated by `scripts/readme-art.mjs`. Edit the generator when changing their artwork, then regenerate the SVG files so the checked-in output remains reproducible.

## 🟩 `screenshots/`

Product screenshots are used by the [full guide](../guides/full-guide.md). Keep screenshots cropped to the feature being discussed, readable at repository scale, and free of secrets or private applicant data.

## 🟨 Link maintenance

The repository README references brand artwork with paths relative to the repository root. Markdown inside `docs/guides/` references screenshots using paths relative to that guide. When moving an asset, update both its generator and every link that uses it.
